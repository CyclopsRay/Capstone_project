# UnDetect demo: a reproducible pipeline

[![Reproduce](https://github.com/CyclopsRay/Capstone_project/actions/workflows/reproduce.yml/badge.svg)](https://github.com/CyclopsRay/Capstone_project/actions/workflows/reproduce.yml)

A small, complete pipeline that trains and tests UnDetect, a model that predicts how cells' gene expression changes
under a compound the model has never seen, on simulated data. It shows the parts of a reproducible analysis: a
locked software environment (Pixi), a workflow (Snakemake), a report computed from the results (Quarto), and a
check from a clean clone on every push (GitHub Actions).

**Paper:** Lei Y, Liang H, Peng K, Wen J. *Predicting Transcriptional Responses to Unseen Compounds through Context
Modeling and Multi-View Transfer.* bioRxiv, 2026.
[doi:10.64898/2026.11.05.764505](https://doi.org/10.64898/2026.11.05.764505)

## Run the demo

You need [Pixi](https://pixi.sh) and an internet connection, on Linux (x86-64) or macOS (Apple silicon).

```bash
git clone https://github.com/CyclopsRay/Capstone_project.git
cd Capstone_project
pixi run reproduce
```

The first run installs the environment from `pixi.lock` (a 330 to 420 MB download), then runs the pipeline and
writes the report `reports/undetect-demo.html`. On GitHub's runner (4 CPU cores, nothing cached) the whole run
takes about 5 minutes.

| Command | What it does |
|---------|--------------|
| `pixi run reproduce` | runs the whole pipeline; afterwards, only the steps whose inputs, code or settings changed |
| `pixi run dry-run` | lists the steps that would run, and why |
| `pixi run test` | runs the unit tests |
| `pixi run report` | renders the report again from the current results |

**Hardware:** any recent laptop. A fold needs at most 1 GB of memory (Snakemake runs folds in parallel; 4 GB is
enough); the environment takes 1.6 GB of disk.

## What the pipeline does

1. **download**: the CLUE compound table (4.6 MB): structures, targets and mechanisms of action of real compounds.
   Checked against `metadata/checksums.sha256` and kept read-only in `data/raw/`.
2. **simulate**: picks 240 of these compounds and simulates their responses in 8 cell lines (978 genes), with a
   known answer (`data/processed/`).
3. **train**: trains and tests UnDetect on 5 folds. Each fold holds out a fifth of the compounds for testing and
   another fifth for choosing the settings, so every test compound is new to the model.
4. **evaluate**: PCC_DEG (the correlation of measured and predicted response across genes) of each stage of the
   model on training, validation and test compounds (`results/`).
5. **report**: `reports/undetect-demo.html`, with every number, table and figure computed when it renders.

Every setting is in `config/config.yaml`.

## Outputs

- `reports/undetect-demo.html`: the report
- `results/scores.csv`: PCC_DEG by fold, split and stage; `results/view_weights.csv`; `results/summary.json`
- `results/folds/fold_<f>/`: scores of every sample, chosen settings and test predictions of each fold
- `results/logs/`: one log per step

## Repository

```
config/config.yaml      settings of the simulation and the model
workflow/Snakefile      the pipeline
scripts/undetect/       the model: kernels.py, backbone.py, model.py, metrics.py
scripts/*.py            one script per step: download_data, simulate_data, train, evaluate
reports/                the Quarto report
tests/                  unit tests of the model
metadata/               data source, license and checksum
containers/             Dockerfile: the same environment as a container image
pixi.toml, pixi.lock    the software environment
```

## Data, citation and license

The compound table comes from CLUE (LINCS2020 release); `metadata/sources.tsv` lists its source and terms. All other
data are simulated by `scripts/simulate_data.py` and regenerated by the pipeline; no data are stored in this
repository. The model is UnDetect ([Lei et al., bioRxiv 2026](https://doi.org/10.64898/2026.11.05.764505)); to cite
this repository, see `CITATION.cff`. The code is released under the MIT License (`LICENSE`), the text of the report and documentation
under CC BY 4.0 (`LICENSE-CC-BY-4.0.txt`). Questions: open an issue on GitHub.
